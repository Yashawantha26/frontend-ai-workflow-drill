# Prompt Ladder

## Baseline Prompt (Weak)

Build a website.

### Output
A basic website with a title and a few sections.

### Notes
- What changed: Initial prompt.
- What improved: None.
- What still failed: Too generic.
- Next step: Add a clear goal.

---

## Version 1 – Clear Goal

Build a personal portfolio website.

### Output
A portfolio structure with Home, About, Projects, and Contact.

### Notes
- What changed: Added a clear goal.
- What improved: The AI focused on a portfolio instead of a generic website.
- What still failed: The audience was unclear.
- Next step: Add a target audience.

---

## Version 2 – Audience

Build a personal portfolio website for software recruiters.

### Output
The portfolio highlighted technical skills and projects.

### Notes
- What changed: Added the audience.
- What improved: The content became more relevant to recruiters.
- What still failed: No project details.
- Next step: Add context.

---

## Version 3 – Context

Build a personal portfolio website for software recruiters. I am a Computer Science student with HTML, CSS, JavaScript, Python, and Flask projects.

### Output
The AI included relevant skills and project sections.

### Notes
- What changed: Added project context.
- What improved: The output matched my background.
- What still failed: Layout wasn't specified.
- Next step: Specify the output format.

---

## Version 4 – Output Format

Create the portfolio as responsive HTML, CSS, and JavaScript with sections for Hero, About, Skills, Projects, Education, and Contact.

### Output
The AI generated a complete website structure.

### Notes
- What changed: Specified the output format.
- What improved: The response became more organized.
- What still failed: Accessibility wasn't mentioned.
- Next step: Add quality criteria.

---

## Version 5 – Quality Criteria

Create a responsive HTML, CSS, and JavaScript portfolio for software recruiters. Use semantic HTML, responsive design, accessibility best practices, and clean code.

### Output
The website was responsive, accessible, and well structured.

### Notes
- What changed: Added quality criteria.
- What improved: The code quality increased significantly.
- What still failed: None.
- Next step: Finalize the reusable prompt.

---

# Final Reusable Prompt

Create a responsive personal portfolio website for software recruiters using HTML, CSS, and JavaScript. Include Hero, About, Skills, Projects, Education, and Contact sections. Use semantic HTML, responsive design, accessibility best practices, and clean, readable code.
