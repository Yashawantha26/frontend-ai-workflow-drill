# FL-02 Prompt Iteration Log

## Task

Build a personal portfolio website using HTML, CSS, and JavaScript.

---

## Version 1 – Naive Prompt

**Prompt:**
Build a portfolio website.

**Output:**
A simple website with basic sections.

**Note:**
The response was too generic and lacked project details.

---

## Version 2 – Role Assignment

**Prompt:**
You are an experienced frontend developer. Build a personal portfolio website.

**Output:**
The website had a better structure and cleaner code.

**Note:**
Assigning a role improved the quality and professionalism of the response.

---

## Version 3 – Context and Motivation

**Prompt:**
You are an experienced frontend developer. Build a portfolio website for a Computer Science student applying for internships.

**Output:**
The AI included projects, skills, and contact information relevant to recruiters.

**Note:**
Adding context made the output more targeted.

---

## Version 4 – Few-Shot Example

**Prompt:**
Use this structure:
Hero
About
Skills
Projects
Contact
Now build a similar portfolio.

**Output:**
The response followed the required layout.

**Note:**
The example guided the AI toward the desired format.

---

## Version 5 – Output Structure

**Prompt:**
Generate HTML, CSS, and JavaScript separately with comments.

**Output:**
The code was organized into separate files.

**Note:**
Specifying the output structure made the code easier to understand.

---

## Version 6 – Step Decomposition

**Prompt:**
First plan the website sections, then generate HTML, then CSS, then JavaScript, and finally review the code for accessibility and responsiveness.

**Output:**
The AI created a structured plan followed by clean code and a review.

**Note:**
Breaking the task into steps improved completeness and reduced errors.

---

---

## Final Reusable Prompt

You are an experienced frontend developer. Build a responsive portfolio website using HTML, CSS, and JavaScript for a Computer Science student applying for software internships. Include Hero, About, Skills, Projects, Education, and Contact sections. Use semantic HTML, responsive design, accessible forms, and clean code. Generate HTML, CSS, and JavaScript separately and review the final output for accessibility and responsiveness.
